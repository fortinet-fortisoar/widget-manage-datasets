## Overview

The **Manage Datasets** widget creates and lists datasets, allowing you to save, list, and preview them. A dataset lets you filter module records based on defined filter criteria and reuse that filter as a saved view on a list view panel.

For example, you can add the **Manage Datasets** widget to the **Threat Feeds** tab of the **Threat Intel Management** page, and then create a dataset that filters threat feed records by type.

### Key Features

- Save, list, and preview datasets created from module records
- Filter module records using custom filter criteria when creating a dataset
- Add the widget to the list view panel of any FortiSOAR module
- View all datasets created across modules from a single, central location on the **TAXII Server** tab
